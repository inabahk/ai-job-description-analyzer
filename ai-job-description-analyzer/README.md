# 🔍 AI Job Description Analyzer

> Paste any job description and get instant AI analysis — role type, required skills, red flags, and your resume match score.

[![Python](https://img.shields.io/badge/Python-3.11-blue?style=flat-square&logo=python)](https://python.org)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.115-green?style=flat-square&logo=fastapi)](https://fastapi.tiangolo.com)

## 📌 What It Does

1. **Paste a job description** (and optionally your resume)
2. **AI detects** role type, seniority, required tech skills, and red flags
3. **Get a match score** showing how well your resume aligns
4. **See insights** tailored to the role

## 🧠 AI/ML Concepts Demonstrated

- **NLP / Information Extraction** — keyword extraction, role classification
- **Semantic Matching** — resume-to-JD skill overlap scoring
- **Heuristic AI** — domain-tuned rules for tech hiring intelligence
- **REST API** — clean FastAPI endpoints

## 🚀 Run Locally

```bash
cd backend
pip install -r requirements.txt
uvicorn app:app --reload
```
Open `http://localhost:8000`
