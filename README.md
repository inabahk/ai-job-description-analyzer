# ai-job-description-analyzer
SmartJD — AI Job Description Analyzer
Paste any job description → get skill gap analysis, ATS score, and rewrite suggestions. Built with Python + React. 

1 JD parser
Extracts required skills, experience level, and keywords from any job description using spaCy NER + regex

2 Resume matcher
Upload your resume PDF → scores match % against the JD and highlights missing skills

3 ATS score simulator
Simulates how an ATS system would rank your resume (keyword density, formatting checks)

4 Rewrite suggestions
GPT-powered bullet point rewrites tailored to match the specific JD language
